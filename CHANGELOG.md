# Changelog

## 0.1.0

- Initial The Black Archive prestige-library release.
- Added 24 original rare/unique afflictions from levels 1–20.
- Added periodic stage effects, event reactions, timed residual persistence, alternative stage expiry actions, numeric stage modifiers, concentration gates, condition locks, and healing restrictions.
- Added one weapon injury poison and a unique level-20 death-effect finale.
- Added semantic Creature Forge tags using contract 1.0.0.
- Added DE/EN localization.
- Added Foundry 14-safe managed compendium synchronization and portable release tests.
